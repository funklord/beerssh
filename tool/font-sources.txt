# The curated font set, pinned (project.md sec 9.2, sec 9.4).
#
# One file, read by two things that must agree: tool/fetch-fonts.sh,
# which fetches whole archives for a build and checks them by the
# archive hash, and the app, which fetches single files on a phone
# (bssh_font_download) by HTTP range and checks each by its own hash --
# a 165 MB archive is not a download to make for four fonts in it.
#
#   archive|id|archive-url|sha256|licence-url|licence-file|members...
#
# where each member is  path/inside/archive>OutputName.ttf , or for a
# bare font file the single member  .>OutputName.ttf . A licence-url of
# "archive:<path>" is a member of the archive.
#
#   file|OutputName|sha256
#
# is the hash of each output on its own, taken from files the archive
# hash had already verified; licences are named licences/<file>.
# Changing an archive means re-taking these, or the phone refuses the
# new files as not the ones pinned -- which is the point.
